検査値トラッカー

1検査結果を追加

検体検査結果報告書の写真、またはPDFファイルを選択してください（未記載の項目は自動で無視されます）。

内蔵OCRは同じ様式の報告書向けの簡易読み取りです。誤読があれば次のステップで直接修正できます。

タップして画像 / PDFを選択 カメラ撮影・写真ライブラリ・PDFファイルから選べます

2読み取り結果の確認

身長・体重を記録

検査結果とは別に、いつでも手動で記録できます。どちらか一方だけの入力も可能です。

項目を選択

検査項目をタップすると推移グラフに重ねて表示します（身長・体重・CRE・eGFR・Ca・Li・Na・PHはデフォルト選択）。

推移

記録一覧

患者情報（AI考察用）

年齢や病名を入力しておくと、Geminiによる考察の精度が向上します。

Geminiによる考察

保存済みの検査データおよび患者情報をもとに、傾向や気になる点をGeminiに整理させます。医師の診断に代わるものではありません。

Gemini API 設定

検査結果の読み取り自体は内蔵OCRで完結するため必須ではありません。「考察」機能を使う場合、またはOCRより高精度な読み取りをしたい場合のみ、Google AI StudioでGemini APIキーを発行して登録してください。

Googleスプレッドシート連携

作成したGoogle Apps Script (GAS) WebアプリのURLを登録すると、アプリ内の全データを指定のスプレッドシートにワンタップで送信・登録できます。

データ管理

全記録はこの端末のブラウザ内（localStorage）にのみ保存されます。
